# kinematics
## Constant acceleration

$$v = v_i+at$$

$$s = s_i+v_it+\frac12at^2$$

$$v^2 = v_i^2+2as$$

## Free fall

$$v = gt$$

$$H = \frac12gt^2$$

$$v^2 = 2gH$$

## Inclined plane motion

$$a = g\sin\theta$$

$$\sin\theta = H/S$$

$$t = \frac1{\sin\theta}\sqrt{2H/g}$$

## Projectile
* when $H = H_{max},\ v = 0$
* $t_{up} = t_{down} = v_i\sin\theta/g$
* $s$ is the same in $\theta_i$ & $90^o-\theta_i$

$$v_{ix} = v_i\cos\theta\qquad v_{iy} = v_i\sin\theta$$

$$v = \sqrt{v_x^2+v_y^2}\qquad\theta = \arctan\frac{v_{iy}}{v_{ix}}$$

$$T_{tt} = 2t = \frac{2v_i\sin\theta_i}{g}$$

$$H = \frac{v_i^2\sin\theta_i}{2g},\ \text{if}\ \theta = 90^o,H_{max} = \frac{v_i^2}{2g}$$

$$s = \frac{v_i^2\sin^2\theta_i}{g},\ \text{if},\ \theta = 45^o,s_{max} = \frac{v_i^2}{g}$$

## angular velocity

* unit : $1RPM = 1rev/min = \frac{2\pi}{60}rad/s = 60RPS$

$$\omega = \theta/t\qquad v = s/t = r\theta/t = r\omega$$

if $\omega$ is a constent : $T = 2\pi/\omega,\ f = \omega/(2\pi)$

| angular | linear |
|:--------:|:--------:|
|   $\omega = \omega_i+\alpha t$   |   $v = v_i+at$   |
| $\theta = \omega_i+\frac12\alpha t^2$ | $s = s_i+v_it+\frac12at^2$ |
| $\omega^2 = \omega_i^2+2\alpha\theta$ | $v^2 = v_i^2+2as$ |

## Circular motion

$$a_t = \Delta v/t = v\Delta\theta/t = v\omega = r\omega^2 = v^2/r = \frac{4\pi^2r}{t^2}$$

$$a_{tt} = \sqrt{a_n^2+a_t^2} = \sqrt{(r\omega^2)^2+(r\alpha)^2} = r\sqrt{\omega^4+\alpha^2}$$
